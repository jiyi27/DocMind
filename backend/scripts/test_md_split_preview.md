# API 接口文档

这是一份用于测试分块效果的示例文档，包含多种 Markdown 结构。

## 概述

本系统提供 REST API，支持文档上传、检索和问答功能。

> 注意：所有接口均需要携带 JWT Token，否则返回 401。

## 接口列表

### 上传接口

POST `/api/v1/ingest`，用于将文档加入处理队列。

| 参数       | 类型   | 必须 | 说明                       |
|------------|--------|------|----------------------------|
| file       | File   | 是   | 支持 PDF / Markdown 格式   |
| kb_name    | string | 是   | 目标知识库名称             |
| chunk_size | int    | 否   | 分块大小，默认 500         |
| strict     | bool   | 否   | 是否启用严格模式，默认关闭 |

返回示例：

```json
{
  "doc_id": "d3f1a2b4",
  "status": "queued"
}
```

### 检索接口

GET `/api/v1/search`，根据查询语句进行语义检索。

| 参数    | 类型   | 必须 | 说明                     |
|---------|--------|------|--------------------------|
| query   | string | 是   | 用户查询语句             |
| kb_name | string | 是   | 知识库名称               |
| top_k   | int    | 否   | 返回结果数量，默认为 5   |
| mode    | string | 否   | chunk 或 full_doc        |

## 错误码说明

系统的所有接口统一使用以下错误码规范：

| 错误码 | HTTP 状态 | 含义                   |
|--------|-----------|------------------------|
| 1001   | 400       | 参数缺失或格式错误     |
| 1002   | 401       | 未登录或 Token 已过期  |
| 1003   | 403       | 无权限访问该资源       |
| 1004   | 404       | 资源不存在             |
| 1005   | 500       | 服务器内部错误         |

## 注意事项

> **重要**：上传文件大小限制为 50 MB。超出限制会返回 413 错误。
>
> 建议在生产环境中启用严格分块模式，以获得更好的检索质量。

以下情况会触发降级处理：

> 如果文档中存在超过 max_chunk_size 的单段文字，严格模式会抛出异常。
> 建议在上传前对文档进行预处理，确保段落长度在合理范围内。

## 部署要求

系统依赖以下组件：

| 组件      | 版本要求 | 必须 | 说明                    |
|-----------|----------|------|-------------------------|
| Qdrant    | >= 1.7   | 是   | 向量数据库              |
| Redis     | >= 7.0   | 否   | 任务队列（可选）        |
| PostgreSQL| >= 15    | 是   | 元数据存储              |
| Python    | >= 3.11  | 是   | 运行时环境              |
