# OpenAI-Compatible Chat Completions API

`/api/v1/chat/completions` should be treated as an OpenAI-compatible chat
completions endpoint.

For standard request and response behavior, follow the normal OpenAI chat
completions contract. DocMind adds one extra top-level field:

- `citations`

## `citations`

`citations` is a document-level source list returned alongside the assistant
answer.

Example:

```json
{
  "citations": [
    {
      "index": 1,
      "title": "DocMind Overview",
      "url": "https://example.com/docmind",
      "sourceLabel": "[1] [DocMind Overview](https://example.com/docmind)"
    }
  ]
}
```

Field meanings:

- `index`: 1-based citation number, intended to match answer markers like `[1]`
- `title`: human-readable source title
- `url`: source URL, may be empty
- `sourceLabel`: preformatted display label generated by the backend

## Rendering Guidance

- Render source links from `citations`, not by parsing the assistant text.
- The assistant text may contain inline markers such as `[1]`.
- `citations[index]` is the source metadata for display purposes.
- `sourceLabel` is a convenience display field, not a stable identifier.

## Streaming Behavior

When `stream=true`:

- the response still follows the normal OpenAI-compatible SSE chunk format
- `citations` appears once on the initial assistant chunk
- later chunks only contain incremental `delta.content`

Example initial chunk:

```json
{
  "id": "chatcmpl-...",
  "object": "chat.completion.chunk",
  "choices": [
    {
      "index": 0,
      "delta": { "role": "assistant" },
      "finish_reason": null
    }
  ],
  "citations": [
    {
      "index": 1,
      "title": "DocMind Overview",
      "url": "https://example.com/docmind",
      "sourceLabel": "[1] [DocMind Overview](https://example.com/docmind)"
    }
  ]
}
```

## Current Scope

- `citations` is a source list, not a span/annotation format
- the API does not currently return exact start/end offsets for citations
- clients should treat `citations` as answer-level metadata
